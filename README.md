# Minimalist Notepad - nai

This is a minimalist notepad application that heavily encourages the use of keyboard navigation.

### Note: Windows may show a "Windows protected your PC" screen, Click More info, then Run anyway.

## About nai

Nai is inspired by keyboard-driven text editors. It is a minimalistic notepad application. 
Very straightforward functions. It can read and write text files and it has the basic typography
and font size alterations.

## Keyboard Shortcuts

By pressing "ctrl + z + x" on the keyboard, the user can view nai's list of keyboard shortcuts. It is easy to memorize as most of these
are the traditional keyboard shortcuts.

<img width="736" height="533" alt="Showcasehelp" src="https://github.com/user-attachments/assets/b277a9f2-c606-4c7b-8eef-f202596b1346" />

## Features

Built-in tab list for open txt files (ctrl + tab). The user would be able to cycle seamlessly through their open files by pressing "ctrl + 1-9".
